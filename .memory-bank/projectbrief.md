# Project Brief

## Overview
Personal blog for Caio Incau (caio.dev), built with Jekyll using the "Will Jekyll Template". The blog focuses on technology, career development, and personal insights.

## Core Requirements
- Static blog site generation using Jekyll
- Asset compilation via Gulp (Stylus for CSS, JS minification)
- Live development environment with BrowserSync
- Blog posts in Markdown format with YAML front matter
- Responsive design with minimalist aesthetic

## Goals
- Provide a platform for writing about technology, career, and personal topics
- Maintain a fast, lightweight blog with minimal frontend complexity
- Easy content creation via shell script (`initpost.sh`)
- SEO-friendly with sitemap, RSS feed, and proper meta tags

## Target Audience
- Portuguese-speaking readers interested in tech, career advice, and personal development
- Blog is written primarily in Portuguese (pt-br)

## Key Features
- Tags and categories support
- Series pages for multi-part posts
- About page
- Comments via Disqus
- Social sharing integration
- Search functionality
- SVG icons
- Color customization through Stylus variables
